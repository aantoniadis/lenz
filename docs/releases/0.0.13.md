# Lenz 0.0.13 — draft release notes

This release is being prepared from [PR #47](https://github.com/aantoniadis/lenz/pull/47). The version tag, release assets and publication are pending.

## Changes

- View a specific commit with `lenz diff show <commit>`. It compares committed bytes with the first parent, or the empty tree for a root commit, supports path filters, and keeps empty commits visible.
- Start file, folder or repository comparisons from the Diff chooser or **New Comparison…**. New comparisons retain independent documents and drafts. Invalid paths remain editable, and Reader provides a path prompt if the native picker fails.
- Search and popup text fields in Reader and Diff now support Unicode-aware character and word movement/deletion, Home/End, Shift-selection, select-all, copy, cut and paste. Paired fields retain their own selections. Terminal fields support bracketed paste and OSC 52 clipboard output where the terminal permits them.
- Improve narrow Find bars, comparison layouts and merge recovery guidance. Keep focused popup input from editing an underlying document or reaching the shell.
- Home/End edit the focused field; Alt-Home/End retain supported first/last-result navigation. Reader uses Alt-Enter for row actions with a nonempty filter and F6 to forget a recent item/bookmark or reset a keybinding. See [text-input controls and terminal limits](../tui.md#text-in-searches-and-dialogs).
- Clarify how to link the Homebrew macOS app into `/Applications` for Launchpad and Spotlight.

## Validation and measured costs

The runtime changes passed the full local CI gate with four test workers, native Linux/X11 keyboard and exact clipboard checks, Unicode PTY checks, narrow layouts, source/file isolation, terminal restoration, standalone TUI builds and the GUI stripped-size check. The only upstream change incorporated before merging was Homebrew documentation.

Performance measurements use two successive baselines. Against the preceding journey fixes, the text-field changes retained about 1.4 MiB more resident executable pages in Reader GUI; anonymous-memory ranges overlapped. Repeated Reader TUI source stress measured about 0.03 ms more first-byte feedback. The earlier journey comparison against 0.0.12 retained about 0.6–0.8 MiB more TUI file-backed RSS. These are residency and feedback measurements, not completed-display timings or proof of leak freedom.

See the [journey measurements](../optimization-notebook.md#journey-input-and-comparison-entry-2026-11-08) and [text-field measurements](../optimization-notebook.md#search-and-popup-text-editing--2026-11-09). Raw evidence is retained locally under `perf-results/journey-fixes/` and `perf-results/popup-inputs/`.

## Before publishing

- Run the [release checklist](../release-checklist.md) on the final release commit, including Linux and native macOS package/manual checks. The new native macOS and Wayland interactions, host terminal clipboard permissions, physical-display behavior and longer leak runs remain unverified.
- Tag the approved version commit `v0.0.13` and push the tag to run the existing three-platform packaging workflow. Check the resulting draft release's tarballs and checksums; use the changes above as its notes.
- Download the actual release checksums and run `packaging/bump.sh 0.0.13` to update Homebrew and AUR metadata. Existing package checksums remain on 0.0.12 until those assets exist.
- Publish the draft and update the package distribution channels after release acceptance.
