# Lenz 0.0.14 beta

This release brings archive editing, project-wide replacement and symbol rename,
more direct language-server setup, and faster Find. The five commands remain
`lenz`, `lenz-code`, `lenz-code-tui`, `lenz-diff` and `lenz-diff-tui`.

## Changes

- Edit archive members, including nested archives, with guarded saves and
  recovery. Improve external-change handling, input routing and navigation.
- Create scratch files through a kind picker, improve Search Everywhere and
  navigation, and optionally save when leaving a file. Preserve syntax feedback
  when returning to edited files, including shared split views.
- Replace text across a project or rename a symbol through its language server.
  Review affected files, control inclusion and cancel before applying. Changes
  go to drafts with independent per-file Undo; Save preserves source encoding
  and line endings.
- Open language-server setup directly from missing-server status or F2. Choose
  an existing Node runtime before installing its server. Managed setup includes
  progress, cancellation, details and retry, plus curated Ruby LSP and gopls
  recipes using existing toolchains and private installation directories.
- Speed up bounded ASCII Find collection while retaining Unicode case folding,
  regular expressions, whole-word matching, cancellation and match limits. Fix
  zero-hit searches leaving the terminal's counter stuck on searching.

## Validation and measured behavior

The merged changes passed the complete local Linux gate, GUI/TUI input and
render replays, light/dark and narrow layouts, exact-byte Save/Undo/Redo checks,
and normal-release sustained workloads. A 100,000-line native TUI Find/reveal
comparison measures **9.88 → 3.45 ms** in three alternating process pairs.
Hot scans measure **7.17 → 1.97 ms** for an absent ASCII literal and
**16.19 → 1.48 ms** for a sparse case-sensitive literal. These compare successive
implementation baselines, not pristine 0.0.13 release packages; they do not
measure physical display latency or establish indefinite leak freedom.

See [replacement/rename validation](../research/project-replace-rename-validation.md)
and [feedback/setup/Find validation](../research/editor-feedback-setup-search-validation.md)
for identities, actual stress duration, memory modes and retained failures.
Release-commit and package results are recorded during publication.

Real npm and a fresh offline Ruby installation pass. Live Ruby registry discovery
and a complete Go dependency download were blocked in the validation environment.
Native macOS/Wayland interactions, physical display behavior and prolonged
external-provider sessions remain unverified. macOS packages are ad-hoc signed.

## Install

Keep the archive's five executables together. On macOS they are inside `Lenz.app`,
with a symlink for each executable. Git 2.30 or later is required; Linux packages
target glibc 2.35 or later, and Apple Silicon packages target macOS 11 or later.
Verify the matching `.sha256` sidecar before installation.
